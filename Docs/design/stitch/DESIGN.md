## Brand & Style

This design system blends institutional financial clarity with celestial calm. Built for high-trust conversational wealth intelligence, the visual aesthetic merges the airy utility of leading investment platforms with an understated cosmic narrative: delicate orbital traces, starlight micro-accents, and ambient atmospheric depth.

### Brand Values
- **Atmospheric Clarity:** Complex portfolio analysis presented with spacious, serene restraint.
- **Quiet Intelligence:** An AI assistant that feels patient, mathematically rigorous, and quietly assured.
- **Architectural Polish:** Apple-inspired precision mechanics paired with tactile financial instruments.

### Visual Style
Minimalist Neo-Elegance with subtle cosmic textures. Surfaces rely on pure whites, gentle atmospheric greys, hairline orbital dividers, and faint emerald nebulas. Avoid game-engine neons, aggressive multi-color aurora gradients, or heavy skeumorphic glass. Luminosity is reserved strictly for affirmative monetary signals and assistant focus rings.

## Colors

The palette is rooted in an ultra-disciplined monochrome green continuum layered over clean celestial neutrals.

### Palette Architecture
- **Primary Green (`#00B386`):** The primary signal for value growth, conversational focus states, active prompts, and radiant nodes.
- **Deep Green (`#008A65`):** The grounding shade for interactive button presses, high-emphasis text links, and anchored call-to-actions.
- **Light Green (`#E6F7F2`):** The celestial wash used for positive delta callouts, active chip fills, and subtle assistant response backdrops.
- **Pure White (`#FFFFFF`):** Base canvas for user message bubbles, high-tier cards, and primary surfaces.
- **Soft Canvas Background (`#F7F8FA`):** Atmospheric base tone that prevents screen glare and provides depth beneath white cards.
- **Dark Text (`#44475B`):** Deep charcoal delivering optimal contrast for primary balances, responses, and metrics.
- **Secondary Text (`#7C7E8C`):** Muted slate for time-stamps, secondary metrics, tickers, and helper labels.
- **Subtle Cosmic Border (`#EAECEF`):** Architectural boundary lines and orbital rings; provides crisp distinction without visual clutter.

### Semantic Rules
Never introduce alien accent colors (no purple, yellow, or electric blues). Warnings and downward trends rely on subdued, desaturated earthen-rose (`#D9534F`), ensuring primary emerald greens remain the undisputed focal energy.

## Typography

The type hierarchy prioritizes conversational readability and rapid fiscal data absorption.

- **Primary Typeface (`Plus Jakarta Sans`):** Selected for its geometric structure softened by organic warmth. It mirrors institutional precision while remaining friendly and conversational in long-form generative chat replies.
- **Metric Typeface (`Space Grotesk`):** Applied exclusively for portfolio asset tags, numeric percentage changes, stock ticks, and timestamps to introduce a subtle aerospace/scientific instrument feel.

### Typographic Treatments
- Financial totals and portfolio valuation numbers should feature tabular figures (`font-variant-numeric: tabular-nums`) to prevent jittering during streaming updates.
- Keep assistant text blocks scannable: paragraphs should not exceed 3 sentences before breaking into bullet points, mini stat bars, or card carousels.

## Layout & Spacing

The conversational interface relies on a centered, high-focus single column container flanked by expansive breathing room on desktop, morphing into a docked layout on mobile.

### Spatial Model
- **Mobile Viewport (<768px):** Single-column layout with fixed chat input dock at the bottom edge. Outer screen padding is pinned to `margin` (`1rem`). Consecutive messages within the same role stack at `space-xs`, while turns between user and bot stack at `space-lg`.
- **Tablet / Desktop (≥768px):** Chat thread is confined to a maximum reading container width of `720px` (or `880px` when rich financial cards and comparison tables stream into view).
- **Rhythm:** An 8-point base spatial system. Compact tokens (`space-2xs`, `space-xs`, `space-sm`) structure metadata clusters and badge chips; macro tokens (`space-lg`, `space-xl`, `space-2xl`) frame assistant response modules and contextual insight containers.

## Elevation & Depth

Visual hierarchy uses physical elevation sparingly, relying instead on low-contrast architectural borders, surface shifts, and faint celestial luminosity.

### Layering Philosophy
- **Base Canvas:** Flat `#F7F8FA` acting as deep, quiet ground.
- **Card Tier 1 (Chat & Insights):** Pure `#FFFFFF` resting over canvas with a hairline outline of `1px solid #EAECEF`. Shadow: `0px 2px 8px -2px rgba(68, 71, 91, 0.04), 0px 1px 2px -1px rgba(68, 71, 91, 0.02)`.
- **Orbital Focus Tier:** Active or hovered portfolio cards subtly expand with a gentle radial emerald halo: `box-shadow: 0 0 0 1px #00B386, 0 8px 24px -4px rgba(0, 179, 134, 0.12)`.
- **Orbital Dividers:** Fine lines resembling planetary trajectories (`1px solid #EAECEF`) punctuated at intersections by faint `2px` round micro-nodes (`#00B386` at 30% opacity).
- **Backdrop Blurs:** Floating input toolbars and pinned prompt docks utilize `backdrop-filter: blur(12px)` over `#FFFFFF` at 88% opacity to let conversation content drift gently underneath without visual chaos.

## Shapes

The geometric identity balances organic curve transitions with structured utility.

- **Base Radius (0.5rem / 8px):** Applied to data grids, input fields, and standard transaction buttons.
- **Large Radius (1rem / 16px):** Standard for incoming assistant conversational cards, interactive prompt cards, and portfolio breakdown panels.
- **Pill Geometry (9999px):** Strictly reserved for suggested quick-reply chips, filter pills, ticker badges, status pills, and the floating chat input pod.
- **Conversation Asymmetry:** User message bubbles feature `1rem` on top and left corners, tapering to `0.25rem` on the bottom right anchor to distinguish origin cleanly. Assistant bubbles mirror this structure across the opposite axis.

## Components

### Buttons
- **Primary Action Button:** Solid `#00B386` background, `#FFFFFF` text, `font-weight: 600`, height `44px`, padding `0 1.25rem`, radius `8px`. Transitions smoothly to `#008A65` on hover. Disabled state shifts to `#EAECEF` background with `#7C7E8C` text.
- **Ghost/Tertiary Button:** Transparent fill, `1px solid #EAECEF` outline, `#44475B` text. On hover, shifts to `#E6F7F2` surface and `#008A65` border.

### Chips & Quick Prompts
- **Portfolio & Suggested Query Chips:** Height `32px`, pill-shaped (`9999px`), background `#FFFFFF`, border `1px solid #EAECEF`, font size `13px`, text color `#44475B`. Contains a tiny `4px` emerald dot on the left. Hover adds a delicate emerald ring `border-color: #00B386` and background `#E6F7F2`.

### Chat Message Bubbles
- **User Message:** Aligned right, `#E6F7F2` background, `1px solid rgba(0, 179, 134, 0.2)` border, `#44475B` text, padding `0.875rem 1.125rem`, border-radius `16px 16px 4px 16px`.
- **Assistant Message:** Aligned left, `#FFFFFF` background, `1px solid #EAECEF` border, `#44475B` text, border-radius `16px 16px 16px 4px`, padding `1rem 1.25rem`. Prefaced by a small `24px` circular avatar featuring an orbital emerald ring icon.

### Portfolio Insight Cards
Nested seamlessly into the chat stream:
- Border: `1px solid #EAECEF`.
- Header: Asset name in `#44475B` (`title-md`), accompanied by Space Grotesk ticker tag in `#7C7E8C`.
- Valuation Row: Large display value (`headline-md`) alongside a pill badge displaying `+12.4%` (styled with `#E6F7F2` fill and `#008A65` text).
- Chart Sparkline: Ultra-clean monochromatic `#00B386` line with no background grid lines, terminating in an illuminated `4px` starlight node.

### Input Bar (Docked)
- Floating capsule container centered at viewport bottom.
- Background: `rgba(255, 255, 255, 0.94)`, `backdrop-filter: blur(16px)`, border: `1px solid #EAECEF`, shadow: `0 8px 32px rgba(68, 71, 91, 0.06)`, border-radius: `9999px`.
- Input Field: Unbordered, transparent, placeholder text in `#7C7E8C`.
- Send Trigger: `36px` circle in `#00B386` with white arrow; glows slightly (`0 0 10px rgba(0, 179, 134, 0.35)`) once characters are keyed.

### Cosmic Micro-Elements
- **Loading / Thinking Indicator:** Three starlight dots pulsing sequentially from `#EAECEF` to `#00B386`, framed by a faint rotating orbital SVG ring with a hair-thin `0.75px` stroke.
- **Divider Nodes:** Horizontal thread rules incorporate a centrally placed diamond or circular particle (`#00B386`, 4px), establishing astronomical reference points.
